### Команды

- `/start` : Открывает главное меню;
- `/help`: Показывает информацию о доступных командах (на данный момент отображает информацию некорректно);
- `/point`: Начинает многошаговый диалог с запросом пользовательских данных.

### Кнопки и менюшки

#### Главное меню:

- Профиль: Открывает меню профиля;
- Друзья: Открывает меню друзей;
- О боте: Показывает информацию о боте и разработчиках.

#### Меню профиля:

- Тектовые кнопки с информацией о пользователе;
- Назад: Открывает предыдущее меню.

#### Меню друзей:

- Добавить друга: Открывает неработающее меню поиска друзей;
- Назад: Открывает предыдущее меню.
